# Internationalisation (i18n)

## Stack technique

- **react-i18next**: Intégration React
- **i18next**: Bibliothèque i18n sous-jacente
- **i18next-browser-languagedetector**: Détection automatique de la langue

## Configuration

```typescript
// services/i18n/index.ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import LanguageDetector from 'i18next-browser-languagedetector'

import fr from './locales/fr.json'
import en from './locales/en.json'

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      fr: { translation: fr },
      en: { translation: en }
    },
    fallbackLng: 'fr',
    interpolation: {
      escapeValue: false // React échappe déjà
    },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage']
    }
  })

export default i18n
```

## Structure des fichiers

```
services/i18n/
```

## Utilisation dans les composants

### Hook useTranslation

```tsx
import { useTranslation } from 'react-i18next'

function Library() {
  const { t } = useTranslation()

  return (
    <div>
      <h1>{t('library.title')}</h1>
      {podcasts.length === 0 && (
        <p>{t('library.empty')}</p>
      )}
    </div>
  )
}
```

### Interpolation

```tsx
// Avec variables
t('episode.duration', { minutes: 45 })
// → "45 min"

// Avec date relative
t('library.lastUpdated', { time: formatRelativeTime(date) })
// → "Mis à jour il y a 5 minutes"
```

### Pluralisation

```tsx
t('podcast.episodeCount', { count: 1 })
// → "1 épisode"

t('podcast.episodeCount', { count: 42 })
// → "42 épisodes"
```

### Changement de langue

```tsx
import { useTranslation } from 'react-i18next'

function LanguageSettings() {
  const { i18n } = useTranslation()

  const languages = [
    { code: 'fr', name: 'Français' },
    { code: 'en', name: 'English' }
  ]

  return (
    <select
      value={i18n.language}
      onChange={(e) => i18n.changeLanguage(e.target.value)}
    >
      {languages.map(lang => (
        <option key={lang.code} value={lang.code}>
          {lang.name}
        </option>
      ))}
    </select>
  )
}
```

## Ajout d'une nouvelle langue

1. Créer le fichier `locales/[code].json`
2. Copier `fr.json` comme base
3. Traduire toutes les chaînes
4. Ajouter l'import dans `index.ts`:

```typescript
import de from './locales/de.json'

// Dans resources:
de: { translation: de }
```

5. Ajouter dans le sélecteur de langue

## Bonnes pratiques

### Clés

- Utiliser des clés hiérarchiques: `section.element.action`
- Éviter les clés trop longues
- Grouper par fonctionnalité, pas par écran

### Textes

- Garder les traductions concises (UI mobile)
- Utiliser des termes cohérents (toujours "podcast" pas "émission")
- Inclure le contexte si ambigu

### Pluralisation

- Toujours définir les formes singulier/pluriel
- En français: `_one` et sans suffixe (pluriel par défaut)
- Tester avec 0, 1, 2, et grands nombres

### Dates et nombres

```tsx
// Dates: utiliser date-fns ou Intl
import { formatDistanceToNow } from 'date-fns'
import { fr, en } from 'date-fns/locale'

const locales = { fr, en }

function formatRelative(date: Date, locale: string) {
  return formatDistanceToNow(date, {
    addSuffix: true,
    locale: locales[locale]
  })
}

// Nombres: utiliser Intl
function formatNumber(n: number, locale: string) {
  return new Intl.NumberFormat(locale).format(n)
}
```

## Tests

```typescript
// Wrapper pour les tests
import { I18nextProvider } from 'react-i18next'
import i18n from '../services/i18n'

function renderWithI18n(component: React.ReactElement) {
  return render(
    <I18nextProvider i18n={i18n}>
      {component}
    </I18nextProvider>
  )
}

// Test
it('displays translated text', () => {
  i18n.changeLanguage('fr')
  renderWithI18n(<Library podcasts={[]} />)
  expect(screen.getByText('Ma bibliothèque')).toBeInTheDocument()
})
```
